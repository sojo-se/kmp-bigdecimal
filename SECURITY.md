# Security Policy

## Supported versions

Security fixes are provided for the latest published release.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private
vulnerability reporting for this repository (Security → Advisories → Report a
vulnerability) or email the maintainer at soren@sojo.se.

Include:

- the affected version and target,
- a minimal reproduction,
- the expected and actual behaviour,
- any relevant input sizes or precision settings.

Reports are acknowledged as soon as possible. A fix and advisory will be
published when appropriate.
